# Average Temperature by U.S. City

This Python script visualizes the average annual temperature (°C) for the 100 largest U.S. cities using Plotly and Pandas.

## Requirements

  * Python 3.10 or later
  * pandas
  * plotly

Install dependencies:
```
pip install pandas plotly
```

## Usage
Run the script:
```
python averageTemp.py
```

A Plotly bar chart will open, showing average temperatures by city.

## Description

The script creates a DataFrame of cities and temperatures, pads missing values with NaN if needed, and generates an interactive bar chart using Plotly Express.
